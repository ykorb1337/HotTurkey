# macOS 功能对照

核对日期：2026-10-22。以官方 [功能页](https://getcoldturkey.com/features/) 、[用户指南](https://getcoldturkey.com/support/user-guide/) 及 [官方更新记录](https://getcoldturkey.com/news/) 为范围。只读查看了本机 Cold Turkey Free 4.9 界面；未修改其配置。

“已实现”表示存在可执行逻辑，不代表所有浏览器、设备或 OS 版本均已实测。证据分开列出，不以界面存在代替验证。

| 功能 | HotTurkey 状态 | 证据或差距 |
|---|---|---|
| 域名、子域名、URL、通配符、关键词 | 已实现 | Python 与扩展规则测试；Edge 实测基础拦截 |
| 浏览器内部页（chrome://、edge://、about:） | 已实现并通过真实 Edge 验证 | 命中后关闭单个标签页；通配符保留新标签页、扩展管理和欢迎页，显式指定可拦截；39 个共享匹配样例及导航竞态检查通过 |
| 全互联网、成人 TLD 模式 | 已实现 | `*.*`、`*.xxx`；不是全网成人分类数据库 |
| YouTube 频道拦截/例外 | 已实现，浏览器实测待完成 | 依赖网页频道元数据及 DOM 结构；网页改版可能失效 |
| 各规则独立网站例外 | 已实现 | 单元测试；Edge 实测路径例外 |

| Windows 独有功能 | 不在本轮平台范围 | 用户确认先完整实现 macOS |

## 达到完整替代之前的主要工作

1. 将 Safari 扩展集成到带签名的 Xcode app target，并进行实机验证。
2. 使用授权的特权后台、受保护存储及带签名的安装/卸载路径，补齐跨用户与防篡改机制。
3. 逐一实测浏览器隐私窗口、嵌入内容、YouTube 频道、休眠/唤醒、设备动作与系统通知。
4. 补齐视频处理、分类规模及捐款休息等差距，并逐浏览器验证已实现的交互。
5. 完成 Developer ID 签名、公证、自动更新及旧 macOS、Intel、独立机器安装测试。
